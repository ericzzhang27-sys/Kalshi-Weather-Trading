# Documentation

Project documentation is grouped by purpose:

| Folder | Contents |
|---|---|
| `project/` | Current project spec and working context notes. |
| `presentation/` | Video walkthrough script, UML, and pseudocode deliverables. |
| `specs/` | Long-form build and planning specifications. |

The repository root keeps conventional entry-point files such as `README.md`, `.gitignore`, and `requirements*.txt` so common tools continue to work as expected.
