# Official Data Migration Reproducibility

Run from the repository root:

```powershell
python scripts\build_ndfd_daily_high_archive.py `
  --start-date 2022-01-01 `
  --end-date 2026-05-20 `
  --stream-by-day `
  --purge-cache-after-extract
python scripts\run_day6_data_verification.py
python scripts\build_day7_supervised_table.py
python scripts\build_features.py
python -m src.evaluate_empirical_baseline
python -m src.train_ngboost --mode tune --overwrite-search-results
python -m src.train_ngboost
python -m src.distribution_pricing
python scripts\evaluate_ngboost.py
```

For the distribution-family comparison, the all-in-one comparison script timed
out locally even with compact estimator counts. The current comparison report
was regenerated by evaluating current36 Normal and Laplace candidates, then
selecting Normal from chronological validation metrics:

```powershell
python -m src.train_ngboost --distribution Normal
python -m src.distribution_pricing
python scripts\evaluate_ngboost.py
# snapshot outputs/reports/ngboost_evaluation_report_normal_current36.csv

python -m src.train_ngboost --distribution Laplace
python -m src.distribution_pricing
python scripts\evaluate_ngboost.py
# snapshot outputs/reports/ngboost_evaluation_report_laplace_current36.csv
```

The final selected run is the configured Normal NGBoost model:

```powershell
python -m src.train_ngboost
python -m src.distribution_pricing
python scripts\evaluate_ngboost.py
```
